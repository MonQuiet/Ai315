# 套壳与虚假宣传黑名单

用于记录疑似以“自研旗舰模型”为名、实为套壳开源模型且定价不透明的产品案例。

## 收录标准
- 有公开可核验证据
- 描述客观、可复现
- 不包含人身攻击

## 状态定义
- 待核验：证据不完整或尚需复现实验确认
- 已核验：证据充分且可复现
- 已更正：后续发现与事实不符并完成修正

## 证据等级
- A 级：官方公告 / 抓包记录 / 可复现实验材料
- B 级：多来源截图 / 对比测试 / 可信第三方报道
- C 级：单一截图或口述线索（仅作为待核验）

## 记录模板
- 产品名
- 宣传口径
- 实测行为
- 鉴伪测试结果（参考：docs/api_fraud.md）
- 证据链接
- 结论状态（待核验/已核验/已更正）

## 示例记录（虚构，仅用于格式展示）

- 鉴伪测试结果：身份认同测试出现第三方模型特征
- 证据链接：示例链接
- 结论状态：待核验
