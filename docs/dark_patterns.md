# 隐私侵权与订阅陷阱

记录 AI 产品中的隐私滥用与 dark patterns（黑模式）设计。

## 常见模式
- 默认开启训练且难以关闭
- 免费试用绑定自动续费
- 取消路径复杂且误导

## 状态定义
- 待核验：证据不完整或尚需复现实验确认
- 已核验：证据充分且可复现
- 已更正：后续发现与事实不符并完成修正

## 证据等级
- A 级：完整流程录屏 / 产品条款截图 / 官方公告
- B 级：多来源截图 / 对比测试 / 可信第三方记录
- C 级：单一截图或口述线索（仅作为待核验）

## 建议输出
- 模式名称
- 触发流程
- 风险评估
- 规避建议

## 示例记录（虚构，仅用于格式展示）
- 模式名称：隐蔽自动续费
- 触发流程：试用期结束自动扣费且关闭路径不明显
- 风险评估：用户可能在不知情情况下产生持续扣费
- 规避建议：提供清晰的取消入口与提前提醒
