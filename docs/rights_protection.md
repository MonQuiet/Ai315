# 退费维权与权益缩水曝光台

记录 AI 产品在订阅、退费、额度与并发限制方面的争议问题。

## 典型问题
- 无理由拒绝退费
- 单方面下调额度/并发
- 隐式变更计费规则

## 状态定义
- 待核验：证据不完整或尚需复现实验确认
- 已核验：证据充分且可复现
- 已更正：后续发现与事实不符并完成修正

## 证据等级
- A 级：购买页面承诺截图 / 账单 / 官方公告
- B 级：多来源截图 / 对比时间线 / 可信第三方记录
- C 级：单一截图或口述线索（仅作为待核验）

## 证据要素
- 购买页面/承诺截图
- 变更公告（若有）
- 账单与时间线
