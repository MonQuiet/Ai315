# AI 诈骗案例与防范指南

收录 AI 语音合成、换脸视频、伪造客服等诈骗案例。

## 案例字段
- 时间/地区
- 诈骗手法
- 损失类型
- 关键证据
- 防范建议

## 状态定义
- 待核验：证据不完整或尚需复现实验确认
- 已核验：证据充分且可复现
- 已更正：后续发现与事实不符并完成修正

## 证据等级
- A 级：警方通报 / 官方公告 / 完整录音录屏
- B 级：多来源报道 / 截图 / 可信第三方记录
- C 级：单一截图或口述线索（仅作为待核验）

## 使用说明
本页面用于公众教育，不构成法律建议。

## 示例记录（虚构，仅用于格式展示）
- 时间/地区：2025-01 / 某地
- 诈骗手法：AI 语音仿冒亲属紧急求助
- 损失类型：转账损失
- 关键证据：通话录音片段与转账记录
- 防范建议：核实身份、多渠道确认
