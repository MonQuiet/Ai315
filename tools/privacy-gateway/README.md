# privacy-gateway（规划中）

本目录用于 Prompt 数据脱敏网关的后续实现。

## 目标
- 在请求发往云端模型前识别敏感信息
- 执行脱敏替换策略
- 在返回结果中按规则恢复上下文

## 设计草案（初版）
### 数据流
1. 客户端请求进入本地代理
2. 识别敏感字段并生成脱敏映射
3. 将替换后的 Prompt 发往云端
4. 接收模型响应并按映射恢复
5. 返回给客户端

### 脱敏策略
- 规则优先（手机号、邮箱、身份证、密钥前缀）
- 可插拔的正则/词典匹配
- 可选 LLM 再识别（本地/可控）

### 恢复策略
- 仅对本次会话生效的短期映射
- 过期自动清理，防止长期存储敏感信息

### 威胁模型
- 防止敏感信息被上传至第三方模型
- 防止日志/错误上报泄露明文
- 避免映射缓存泄露导致可逆恢复

### 非目标
- 不替代安全审计与合规流程
- 不保证对所有敏感信息的 100% 识别
